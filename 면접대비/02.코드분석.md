## 🏗️ 1. Pydantic을 활용한 데이터 정형화 및 검증 (Backend)

**[코드 포인트: `backend/main.py`]**

```python
class TaskItem(BaseModel):
    업무: str = Field(..., description="할 일 요약")
    담당자: str = Field(..., description="할 일 담당자")
    마감기한: str = Field(..., description="사용자가 읽기 편한 문자열")
    마감기한_iso: str = Field(..., description="구글 캘린더용 ISO-8601 포맷")
    우선순위: str = Field(..., description="중요도 (높음/중간/낮음)")
```

*   **설명:** 단순히 AI에게 텍스트를 받는 것이 아니라, `Pydantic` 모델을 통해 **엄격한 데이터 스키마를 정의**했습니다.
*   **면접 어필 포인트:** 
    *   "AI 응답의 불확실성을 최소화하고, 프론트엔드와 백엔드 간의 데이터 규격을 일관되게 유지했습니다."
    *   "특히 `마감기한_iso`와 같이 시스템 연동을 위한 전용 필드를 미리 정의함으로써 자동화 확장성을 고려했습니다."

## 🎯 2. 동적 프롬프트 엔지니어링 (Dynamic Prompting)

**[코드 포인트: `backend/main.py`]**

```python
system_prompt = f"""
이 회의가 진행된 날짜는 기준일 [{req.date}] 입니다. 
반드시 이 기준일을 바탕으로 '내일', '이번 주 금요일' 등을 
실제 캘린더 날짜(YYYY-MM-DD)와 시간으로 변환해서 반영하세요.
"""
```

*   **설명:** 파이썬의 `f-string`을 사용해 프론트엔드에서 전달받은 실제 날짜(`req.date`)를 **실시간으로 지시문에 주입**합니다.
*   **면접 어필 포인트:** 
    *   "고정된 프롬프트가 아닌, **사용자 컨텍스트(날짜 정보)에 반응하는 동적 프롬프트**를 구현하여 AI의 시간 추론 정확도를 극대화했습니다."
    *   "이를 통해 AI 모델이 가진 '환각(Hallucination)' 현상을 제어하고 실무에서 바로 사용 가능한 결과물을 뽑아낼 수 있었습니다."

## ⚡ 3. 비동기 처리와 모델 설정 최적화

**[코드 포인트: `backend/main.py`]**

```python
model = genai.GenerativeModel(
    model_name="gemini-2.5-flash",
    system_instruction=system_prompt,
    generation_config={"response_mime_type": "application/json"}
)

response = await model.generate_content_async(req.text)
```

*   **설명:** `await`와 `async`를 사용한 비동기 호출과, 응답 형식을 JSON으로 강제하는 설정을 적용했습니다.
*   **면접 어필 포인트:** 
    *   "응답 속도가 가장 빠른 **Flash 모델**을 선택하고, **비동기 통신**을 구현하여 사용자 대기 시간을 최소화했습니다."
    *   "`response_mime_type: application/json` 설정을 통해 AI가 별도의 마크다운 기호를 붙이지 않고 순수 JSON만 반환하도록 하여 파싱 에러를 원천 차단했습니다."

## 📅 4. 표준 ICS 캘린더 포매팅 알고리즘 (Frontend)

**[코드 포인트: `frontend/app.py`]**

```python
def generate_ics(tasks):
    lines = ["BEGIN:VCALENDAR", "VERSION:2.0", ...]
    for task in tasks:
        iso_str = task.get("마감기한_iso", "")
        dt = str(iso_str).replace("-", "").replace(":", "").replace(" ", "")
        lines.append("BEGIN:VEVENT")
        lines.append(f"DTSTART:{dt}")
        # ... (생략)
    return "\r\n".join(lines)
```

*   **설명:** AI가 추출한 ISO 날짜 데이터를 캘린더 표준 규격인 `iCalendar(RFC 5545)` 형식으로 직접 변환하는 로직입니다.
*   **면접 어필 포인트:** 
    *   "외부 라이브러리 의존성을 줄이기 위해 **표준 포맷 알고리즘을 직접 구현**하여 시스템 경량화를 시도했습니다."
    *   "데이터가 분석에만 머물지 않고, 실무자의 스케줄 관리에 즉시 투입될 수 있는 **실질적인 업무 자동화 파이프라인**을 완성했습니다."

## 🎨 5. 사용자 경험(UX) 중심의 2단 레이아웃 구현

**[코드 포인트: `frontend/app.py`]**

```python
col_left, col_right = st.columns(2)

with col_left:
    with st.container(border=True): # 캘린더 연동 박스
        st.download_button(...)

with col_right:
    with st.container(border=True): # 사내 메신저 공유 박스
        st.code(share_draft)
```

*   **설명:** `st.columns`와 `st.container(border=True)`를 활용하여 결과물을 직관적으로 분류해 보여주는 UI 코드입니다.
*   **면접 어필 포인트:** 
    *   "사용자가 분석 결과를 확인한 후, **'캘린더 등록'과 '공유'라는 다음 행동(Next Action)을 명확하게 선택**할 수 있도록 데이터 시각화 보다는 **직관적인 UX 레이아웃**에 집중했습니다."
    *   "테두리가 있는 깔끔한 박스로 영역을 구분하여 엔터프라이즈 사내 툴과 같은 정돈된 느낌을 주었습니다."
